ACTUALIZARE NUME TEHNIC - 0.3.1

RO
1. Oprește complet serverul.
2. Redenumește folderul vechi al ACESTUI plugin în PAD7RAR-MVP.
   Păstrează data/, content/, nyrium.json, banner.json și setările existente.
3. Scoate DLL-ul principal vechi, fișierul .deps.json vechi și checksum-ul
   acestuia din folderul activ. Păstrează un backup în afara plugins/.
4. Copiază fișierele din server/game/csgo peste game/csgo pe server.
   DLL-ul nou este plugins/PAD7RAR-MVP/PAD7RAR-MVP.dll.
5. Redenumește și folderul configurației acestui plugin în:
   configs/plugins/PAD7RAR-MVP/
   Dacă nu îl redenumești încă, pluginul poate citi configurația veche.
   Configurația din noul folder are prioritate.
6. Pornește serverul. Verifică !mvp, selecțiile, limba și volumul.

Nu lăsa ambele versiuni active. Nu șterge datele jucătorilor.
Nu este necesară o republicare Workshop pentru această redenumire.
Nu copia examples/config.toml peste configurația existentă.

EN
1. Fully stop the server.
2. Rename THIS plugin's old folder to PAD7RAR-MVP.
   Preserve data/, content/, nyrium.json, banner.json and existing settings.
3. Remove the previous main DLL, its .deps.json and checksum from the active
   folder; keep a backup outside plugins/.
4. Merge server/game/csgo into the server's game/csgo.
   The new DLL is plugins/PAD7RAR-MVP/PAD7RAR-MVP.dll.
5. Rename this plugin's configuration folder to configs/plugins/PAD7RAR-MVP/.
   Until renamed, the previous configuration can still be read.
   Settings in the new folder take priority.
6. Start the server and verify !mvp, selections, language and volume.

Do not run both versions simultaneously. Preserve all player data.
No Workshop republishing is required for this rename.
Do not overwrite existing configuration with examples/config.toml.
