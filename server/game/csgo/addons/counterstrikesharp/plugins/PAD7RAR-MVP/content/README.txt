PAD7RAR-MVP: generated custom song and GIF catalogs.
Copy the GENERATED nyrium-custom.json from Nyrium-Content-Tools into this folder.
Use the separate Nyrium-Content-Tools folder to prepare MP3/WAV/GIF assets.
Publish its nyrium_global addon and mount it using mm_extra_addons.
Upload only the generated catalog here, then restart the server.
No separate sounds/soundevents/Panorama server upload is needed.
Only *.json files are loaded. Do not keep .json backup copies here.
Keep every desired custom entry when rebuilding the catalog.
Replacing nyrium-custom.json replaces that catalog's previous entries.
Do not replace or delete player preference files.
